# Качество красного вина

Разбор выборки [Red Wine Quality](https://www.kaggle.com/datasets/uciml/red-wine-quality-cortez-et-al-2009): 1599 красных вин, 11 химических признаков и оценка `quality`. Ноутбук помечает вино как хорошее, если оценка от 7, и обучает случайный лес.

## Файлы

| Файл | Содержание |
|---|---|
| `winequality-red.csv` | Таблица вин, 101 КБ. |
| `red_wine_quality.ipynb` | Загрузка, разбиение, обучение и ошибки. |

## Что делает ноутбук

1. Читает `winequality-red.csv`.
2. Строит `good`: 1, если `quality` ≥ 7, иначе 0.
3. Делит данные **80% / 20%** со стратификацией по `good` (`random_state=42`): 1279 строк на обучение, 320 на тест.
4. Обучает `RandomForestClassifier` (200 деревьев).
5. Считает ошибки I рода (обычное названо хорошим) и II рода (хорошее пропущено).

## Результат

На тесте точность **94.4%** (на обучении 100%). Если всегда отвечать «обычное», точность была бы **86.6%**.

| | Тест |
|---|---|
| Ошибка I рода | 2 из 277 (0.7%) |
| Ошибка II рода | 16 из 43 (37.2%) |

Лес запомнил обучающую выборку. На тесте он почти не повышает обычные вина и пропускает около трети хороших.

## Запуск

Нужны Python 3, Jupyter, pandas и scikit-learn.

```bash
jupyter notebook red_wine_quality.ipynb
```
